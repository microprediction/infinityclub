The Mandelbrot set

Every pixel is a complex number c. Start at 0 and repeat z → z² + c. If z stays small forever the pixel is dark. If it flies off to infinity, the colour says how fast. Click or tap anywhere to zoom in on that spot.

What's going on

A complex number c = a + bi is a point on the plane: a steps right, b steps up. For each such point we run a tiny machine. Start with z = 0, then replace z by z² + c, then do it again, and again. "Iterate" just means repeat.

Try c = −1 by hand: 0, then 0² − 1 = −1, then (−1)² − 1 = 0, then −1, then 0. It bounces between two values forever and never escapes, so −1 is in the set and painted dark. Now try c = 1: 0, 1, 2, 5, 26, 677. It explodes, so 1 is outside, and it escaped quickly, so it gets a bright colour.

The boundary between staying and escaping is the astonishing part. However far you zoom, the edge keeps producing new spirals, seahorses and tiny copies of the whole set. Points a hair apart can behave completely differently, so no amount of magnification ever makes the edge look smooth.
