Shift, stretch, flip

Why f(x − 3) moves the graph right, not left, and how to read any transformed graph at sight.

Name ____________________Date ____________

Tonight's idea

Every graph you will meet this year is a few basic shapes (\(x^2\), \(|x|\), \(\sqrt{x}\), \(1/x\), \(\sin x\), \(2^x\)) that have been slid, stretched or flipped. Learn the four moves and you can sketch anything.

Outside the function changes the output (vertical). \(y = f(x) + k\) lifts every point by \(k\). \(y = a\,f(x)\) multiplies every height by \(a\); if \(a \lt 0\) the graph flips upside down as well.

Inside the function changes the input (horizontal), and it works backwards. Take \(y = f(x - 3)\). To get the output \(f(0)\), you now need \(x = 3\). Every feature of the graph appears 3 units later than it used to, so the graph moves right. Likewise \(y = f(2x)\) reaches \(f(4)\) already at \(x = 2\): everything happens twice as fast, and the graph is squashed horizontally by a factor of 2, not stretched.

Vertical changes do what they say. Horizontal changes do the opposite of what they say, because they act on the input, and the input has to compensate.

Putting it together: \(y = a\,f\big(b(x - h)\big) + k\). Horizontal moves first, and with the inside factored like this the order is: squash horizontally by \(b\), then shift right \(h\). Then the vertical moves: stretch by \(a\) (flip if negative), then lift by \(k\). The order between a vertical stretch and a vertical shift matters: stretching after shifting also stretches the shift.

Two symmetries get names. A function is even if \(f(-x) = f(x)\): the graph is its own mirror image in the \(y\)-axis (\(x^2\), \(\cos x\), \(|x|\)). It is odd if \(f(-x) = -f(x)\): rotate the graph a half turn about the origin and it lands on itself (\(x^3\), \(\sin x\), \(1/x\)). Most functions are neither.

Watch one: two sketches from a formula

\(y = -2(x + 1)^2 + 3\) starting from \(y = x^2\). Inside: \(x + 1 = x - (-1)\), so shift left 1. Outside: stretch by 2, flip because of the minus, lift by 3. The vertex \((0,0)\) goes to \((-1, 3)\) and the parabola opens downward, twice as steep.

\(y = \sqrt{2x - 6}\) starting from \(y = \sqrt{x}\). Trap: this is not a shift right by 6. Factor the inside first: \(\sqrt{2(x - 3)}\). Squash horizontally by 2, then shift right 3. Check with points: \((0, 0)\) on \(\sqrt x\) needs \(2x - 6 = 0\), so it lands at \((3, 0)\). The point \((4, 2)\) needs \(2x - 6 = 4\), so it lands at \((5, 2)\): horizontally it is now 2 from the start instead of 4, which is the squash.

Your turn

  1. Describe how to get each graph from \(y = |x|\): \(y = |x - 2| + 1\); \(\;y = -3|x|\); \(\;y = |2x|\). For the last one, explain why it is also a vertical stretch, and say which other basic shapes have that property.
  2. The point \((2, 5)\) lies on \(y = f(x)\). Give the point it moves to on each of: \(y = f(x) - 3\); \(\;y = f(x + 4)\); \(\;y = 2f(x)\); \(\;y = f(2x)\); \(\;y = f(-x)\); \(\;y = -f(x - 1) + 2\).
  3. Find the equation of the parabola with vertex \((3, -2)\) that passes through \((5, 6)\).
  4. Starting from \(f(x) = x^2\): (a) shift right 2, then stretch vertically by 3, then lift 1. (b) Shift right 2, lift 1, then stretch vertically by 3. Write both results in the form \(a(x - h)^2 + k\) and explain the difference.
  5. Classify each as even, odd or neither: \(x^3 - x\), \(\;x^4 + 2x^2\), \(\;x^2 + x\), \(\;1/x\), \(\;\cos x\), \(\;\sin x\). Prove your answer for \(x^3 - x\) algebraically. Then explain why a polynomial with only even powers is always even.
  6. \(y = f(x)\) is the upper half of the circle of radius 2 centred at the origin, so \(f(x) = \sqrt{4 - x^2}\). Describe the shape of each: \(y = f(x - 2) + 2\); \(\;y = -f(x)\); \(\;y = f(x/2)\); \(\;y = 2f(x)\). Give the width and height of each shape.

Stretch: when a horizontal move is secretly a vertical one

For \(f(x) = x^2\), the horizontal squash \(f(2x)\) equals the vertical stretch \(4f(x)\). For which functions is \(f(bx)\) always a constant multiple of \(f(x)\)? Show that every power function \(x^n\) works, and find the constant.

Now try \(f(x) = 2^x\). Show that \(f(x + 1) = 2f(x)\): a horizontal shift is the same as a vertical stretch. Then try \(f(x) = \log_2 x\) and show \(f(2x) = f(x) + 1\): a horizontal stretch is a vertical shift. Sketch each graph and point to the feature that makes it true. These two facts are the whole reason exponentials and logarithms behave the way they do in the next sheet.

Answers

  1. \(|x - 2| + 1\): shift right 2, up 1. \(-3|x|\): stretch vertically by 3 and flip. \(|2x|\): squash horizontally by 2, but since \(|2x| = 2|x|\) that is the same picture as a vertical stretch by 2. The same happens for any power function: squashing \(x^2\) horizontally by 2 gives \(4x^2\), squashing \(\sqrt{x}\) by 2 gives \(\sqrt2\sqrt x\). It fails for \(\sin x\) or \(2^x\), where \(f(2x)\) is a genuinely different shape.
  2. \((2, 2)\); \((-2, 5)\); \((2, 10)\); \((1, 5)\); \((-2, 5)\); \((3, -3)\).
  3. \(y = a(x - 3)^2 - 2\) with \(6 = 4a - 2\), so \(a = 2\): \(y = 2(x-3)^2 - 2\).
  4. (a) \(3(x - 2)^2 + 1\). (b) \(3\big((x-2)^2 + 1\big) = 3(x - 2)^2 + 3\). Stretching after lifting multiplies the lift too, so the vertex ends at \((2, 3)\) instead of \((2, 1)\).
  5. Odd, even, neither, odd, even, odd. For \(f(x) = x^3 - x\): \(f(-x) = (-x)^3 - (-x) = -x^3 + x = -(x^3 - x) = -f(x)\). Even powers satisfy \((-x)^{2k} = x^{2k}\), so each term is unchanged by \(x \to -x\), so the whole sum is.
  6. \(f(x-2)+2\): the same half-circle moved to centre \((2, 2)\), width 4, height 2. \(-f(x)\): the lower half of the original circle, width 4, height 2 (below the axis). \(f(x/2)\): stretched horizontally by 2, a half-ellipse 8 wide and 2 tall. \(2f(x)\): stretched vertically, a half-ellipse 4 wide and 4 tall.

Stretch. For \(f(x) = x^n\), \(f(bx) = b^n x^n = b^n f(x)\), constant \(b^n\); the squash by \(b\) and the stretch by \(b^n\) are the same picture. For \(2^x\): \(2^{x+1} = 2 \cdot 2^x\), so sliding the graph left by 1 is the same as doubling every height; on the graph, the curve is the same shape at every level, just scaled, which is why it has no "start" and no "end". For \(\log_2 x\): \(\log_2(2x) = \log_2 2 + \log_2 x = 1 + \log_2 x\), so stretching horizontally by 2 lifts the graph by exactly 1; that is why the log graph rises by the same amount from 1 to 2 as from 100 to 200. Both facts are the exponent laws \(2^{m+n} = 2^m 2^n\) and \(\log(xy) = \log x + \log y\) seen as pictures.
