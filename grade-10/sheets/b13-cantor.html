Some infinities are bigger

Count the fractions, then prove the decimals cannot be counted. Cantor's diagonal in one page.

Name ____________________Date ____________

Tonight's idea

How do you compare the sizes of two sets without counting? Pair them off. If every seat in a hall has a person in it and nobody is standing, there are as many people as seats, whatever that number is. Georg Cantor, in the 1870s, took this seriously for infinite sets: two sets have the same size if their members can be matched one-to-one with nothing left over on either side.

Immediately something odd happens. The even numbers can be matched with all the whole numbers: \(1 \leftrightarrow 2,\ 2 \leftrightarrow 4,\ 3 \leftrightarrow 6, \ldots\), \(n \leftrightarrow 2n\). Nothing is left out on either side. So there are "as many" even numbers as whole numbers, even though the evens are only half of them. For infinite sets, a part can be as big as the whole. (If you did Hilbert's hotel in grade 6, this is the hotel's trick.)

A set that can be matched with \(\{1, 2, 3, \ldots\}\) is called countable: you can list its members first, second, third, so that every member eventually appears. The integers are countable: list them as \(0, 1, -1, 2, -2, 3, -3, \ldots\). The fractions look hopeless, since between any two there are infinitely many more, but they are countable too. Lay out all the positive fractions \(\tfrac{p}{q}\) in a grid, row \(p\), column \(q\), and walk the diagonals: all fractions with \(p + q = 2\), then \(p + q = 3\), then \(4\), and so on, skipping any fraction you have already seen in lower terms. Every fraction sits on some diagonal, every diagonal is finite, so every fraction gets a number.

So is everything countable? Cantor's shock: no. The real numbers between 0 and 1 cannot be listed. Suppose someone hands you a list claiming to contain them all, as infinite decimals:

\(r_1 = 0.\mathbf{3}1415\ldots\quad r_2 = 0.5\mathbf{0}000\ldots\quad r_3 = 0.12\mathbf{3}45\ldots\quad r_4 = 0.999\mathbf{9}9\ldots\quad \cdots\)

Build a new number \(d\) by walking down the diagonal: look at the \(n\)-th digit of \(r_n\). If it is 5, make the \(n\)-th digit of \(d\) a 6; otherwise make it a 5. Here \(d = 0.5556\ldots\). Now \(d\) differs from \(r_1\) in the first digit, from \(r_2\) in the second, from \(r_n\) in the \(n\)-th digit, so \(d\) is not anywhere on the list. But \(d\) is a real number between 0 and 1. The list was not complete. And since this works for any list, no list can be complete. The reals are uncountable: a strictly bigger infinity than the whole numbers. (Using only 5s and 6s dodges a subtle snag: \(0.4999\ldots\) and \(0.5000\ldots\) are the same number written two ways, so a number built from 0s and 9s might secretly equal a listed one. A number made of 5s and 6s has only one decimal form.)

Watch one: numbering the integers and the fractions

Integers: send \(n = 0, 1, 2, 3, 4, \ldots\) to \(0, -1, 1, -2, 2, \ldots\). As a formula, \(f(n) = \tfrac{n}{2}\) if \(n\) is even and \(f(n) = -\tfrac{n+1}{2}\) if \(n\) is odd. Every integer is hit exactly once: positive \(m\) comes from \(n = 2m\), negative \(-m\) from \(n = 2m - 1\).

Fractions: along each diagonal \(p + q = d\), read \(p = 1, 2, \ldots, d-1\) and skip anything not in lowest terms. \(d = 2\): \(\tfrac11\). \(d = 3\): \(\tfrac12, \tfrac21\). \(d = 4\): \(\tfrac13\), skip \(\tfrac22\), \(\tfrac31\). \(d = 5\): \(\tfrac14, \tfrac23, \tfrac32, \tfrac41\). \(d = 6\): \(\tfrac15\), skip \(\tfrac24, \tfrac33, \tfrac42\), \(\tfrac51\). \(d = 7\): \(\tfrac16, \tfrac25, \tfrac34, \tfrac43, \tfrac52, \tfrac61\). Numbering them in that order, \(\tfrac34\) is fraction number 14.

Your turn

  1. Write explicit pairings showing that the multiples of 5 and the perfect squares are each the same size as \(\{1, 2, 3, \ldots\}\). Then say in one sentence why "a part can be as big as the whole" is not a contradiction.
  2. Hilbert's hotel is full when infinitely many buses arrive, each carrying infinitely many passengers. Passenger \(p\) on bus \(b\) needs a room. Give a rule that assigns everyone a different room. (Two ideas work: a grid walk like the fractions, or the number \(2^b 3^p\).) Why does the second idea never give two people the same room?
  3. In the diagonal numbering of the fractions, which number does \(\tfrac25\) get? Which fraction is number 20? Show your diagonals.
  4. Here is a list that claims to contain every real number in \((0, 1)\): \[0.14159\ldots,\quad 0.50000\ldots,\quad 0.33333\ldots,\quad 0.75250\ldots,\quad 0.66666\ldots,\quad \ldots\] Write down the first five digits of a number guaranteed not to be anywhere on it, using the 5-or-6 rule, and say which digit rules out which entry.
  5. Two "why not" questions. (a) The whole numbers are countable, so the diagonal trick had better fail for them. Try to run it on a list of all whole numbers written out in digits, and say exactly where it breaks. (b) Why did Cantor's rule change digits to 5 or 6 instead of simply adding 1 to each diagonal digit?
  6. Consider every finite string of letters, digits, spaces and punctuation: every sentence, every book, every formula that could ever be written down, of any finite length. Show this set is countable. (Hint: order by length, then alphabetically.) Now put that together with Cantor's result and draw a startling conclusion about how many real numbers can ever be described.

Stretch: no biggest infinity

For any set \(S\), let \(P(S)\) be the set of all its subsets. If \(S = \{a, b\}\) then \(P(S)\) has four members: \(\{\}, \{a\}, \{b\}, \{a, b\}\). Cantor proved that \(P(S)\) is always strictly bigger than \(S\), even for infinite \(S\). Try to prove it like this. Suppose some pairing \(f\) matches each \(x\) in \(S\) with a subset \(f(x)\), and suppose every subset is hit. Consider the subset \(D = \{x \in S : x \notin f(x)\}\), the elements that are not members of their own partner. Some \(y\) must have \(f(y) = D\). Ask whether \(y\) is in \(D\), and follow both possibilities. What goes wrong? Why does this give an endless tower of ever-bigger infinities?

Answers

  1. \(n \leftrightarrow 5n\) and \(n \leftrightarrow n^2\); every multiple of 5 is \(5n\) for exactly one \(n\), every square is \(n^2\) for exactly one positive \(n\). No contradiction: "same size" was defined as "can be paired off", and for infinite sets that definition simply does not imply "no proper part can be paired with the whole". That implication is a property of finite sets, not a law of logic.
  2. Grid walk: list pairs \((b, p)\) by diagonals \(b + p = 2, 3, 4, \ldots\), and give the \(k\)-th pair room \(k\) (after first moving the existing guests to the odd rooms, say, and using the even rooms for the pairs). Or send passenger \(p\) on bus \(b\) to room \(2^b 3^p\); by unique prime factorisation, \(2^b 3^p = 2^{b'} 3^{p'}\) forces \(b = b'\) and \(p = p'\), so no two people collide. (Rooms not of that form stay empty, which is fine: the point is only that everyone fits.)
  3. Continuing the list in Watch one: numbers 1 to 6 are \(\tfrac11, \tfrac12, \tfrac21, \tfrac13, \tfrac31, \tfrac14\); 7 to 11 are \(\tfrac23, \tfrac32, \tfrac41, \tfrac15, \tfrac51\); 12 to 17 are \(\tfrac16, \tfrac25, \tfrac34, \tfrac43, \tfrac52, \tfrac61\). So \(\tfrac25\) is number 13. Diagonal \(d = 8\): \(\tfrac17\), skip \(\tfrac26\), \(\tfrac35\), skip \(\tfrac44\), \(\tfrac53\), skip \(\tfrac62\), \(\tfrac71\), giving numbers 18 to 21 as \(\tfrac17, \tfrac35, \tfrac53, \tfrac71\). Number 20 is \(\tfrac53\).
  4. Diagonal digits: 1st of the 1st is 1, 2nd of the 2nd is 0, 3rd of the 3rd is 3, 4th of the 4th is 5, 5th of the 5th is 6. Rule gives \(5, 5, 5, 6, 5\): the number \(0.55565\ldots\) It differs from entry 1 in digit 1, entry 2 in digit 2, and so on; continuing the rule down the whole list rules out every entry.
  5. (a) A whole number has finitely many digits. The diagonal construction produces an infinite string of digits with no end, and that is not a whole number at all (it is not \(555\ldots\) going on forever; no such integer exists). So the "new number" is not a member of the set, and nothing is proved. For decimals the infinite string is a legitimate number, which is the whole difference. (b) Adding 1 turns a 9 into 0 (or 10, which is not a digit), and worse, it can produce a number ending in all 9s or all 0s, which might equal a listed number written the other way (\(0.4999\ldots = 0.5\)). Restricting to 5 and 6 avoids both problems.
  6. There are finitely many strings of each length (with an alphabet of \(A\) symbols, \(A^L\) strings of length \(L\)). List all strings of length 1 alphabetically, then length 2, then 3, and so on; every string appears at a finite position. So the set of all possible descriptions is countable. Each description pins down at most one real number, so at most countably many reals can ever be described, named, or computed. The reals are uncountable. Therefore almost every real number is one that no sentence, formula or program can ever single out. We will never meet them individually, yet they make up nearly the whole number line.

Stretch. If \(y \in D\), then by the definition of \(D\), \(y \notin f(y) = D\): contradiction. If \(y \notin D\), then \(y\) fails the membership test, so \(y \in f(y) = D\): contradiction. Both branches fail, so no \(y\) has \(f(y) = D\), so \(f\) misses at least one subset, so no pairing of \(S\) with \(P(S)\) can cover everything. Hence \(P(S)\) is bigger than \(S\). Apply it again: \(P(P(S))\) is bigger still, and so on without end. There is no largest infinity. (Whether there is an infinity strictly between the whole numbers and the reals is the continuum hypothesis; Gödel and Cohen showed the usual axioms of mathematics can neither prove nor disprove it.)
