Infinity Club · Grade 7 · Around the corner · 16

Look and say

1, 11, 21, 1211, 111221. Read each line aloud to get the next. No digit bigger than 3 ever appears, and you can prove it.

Name ____________________Date ____________

Tonight's idea

Start with 1. To make each new line, read the line above aloud, saying how many of each digit you see in a row. Then write down what you said.

1  →  "one 1"  →  11  →  "two 1s"  →  21  →  "one 2, one 1"  →  1211

So every line after the first is a string of pairs: a count, then the digit counted. Only 1, 2 and 3 ever appear. Here is why.

Look at the first line where a 4 shows up. The line above has no 4, so this 4 is a count: "four of something". The line above must hold four equal digits in a row, such as 1111. Cut that line into its own pairs. The four 1s fall as (11)(11), or as (x1)(11)(1y). Either way two neighbouring pairs both count 1s, like "one 1, then one 1". Nobody reads like that: they say "two 1s". So four in a row never happens, and no 4 is ever written.

Watch one: forwards and backwards

Forwards. Read 111221: three 1s, two 2s, one 1. Write 31, 22, 11. The next line is 312211.

Backwards. Which line reads to 1321? Cut it into pairs: 13, 21. That says "one 3, two 1s", so the line was 311.

Stuck. Try 2111. The pairs 21, 11 say "two 1s, one 1", which would be 111. But 111 is read "three 1s", giving 31. So no line reads to 2111.

Your turn

  1. Write the next two lines after 312211.
  2. Start with 3 in place of 1. (a) Write the next four lines. (b) What is the last digit of every line? Explain why it can never change.
  3. Go backwards. Which line reads to (a) 3112? (b) 1221? (c) 211322?
  4. Which of these can be what you get from reading some line aloud? Give a reason each time. (a) 112   (b) 2211   (c) 3323

Stretch: a line that reads itself

Find a two-digit line that does not change when you read it aloud. Then show it is the only two-digit line like that. Hint: the two digits are either equal or different.

Answers

  1. 312211 is one 3, one 1, two 2s, two 1s: 13112221. That is one 1, one 3, two 1s, three 2s, one 1: 1113213211.
  2. (a) 13, 1113, 3113, 132113. (b) Always 3. The last pair of a line counts the last run of the line above, so it ends in the last digit of the line above. The last digit is copied down for ever. Starting from 1, every line ends in 1.
  3. (a) 31, 12: three 1s, one 2. The line was 1112. (b) 12, 21: one 2, two 1s. The line was 211. (c) 21, 13, 22: two 1s, one 3, two 2s. The line was 11322.
  4. (a) No. Every spoken line is made of pairs, so it has an even number of digits, and 112 has three. (b) Yes. 22, 11 says two 2s, one 1: the line 221, which does read "two 2s, one 1". (c) No. 33, 23 says "three 3s, two 3s". That would be 33333, which is read "five 3s": 53.

Stretch. 22 is read "two 2s", which is 22 again. It is the only one. If the two digits are different, the line has two runs and reads to four digits, so it changes. If they are equal, say \(aa\), it reads "two \(a\)s", written \(2a\). That matches \(aa\) only when \(a = 2\).
