Multiplying by halving and doubling

Halve one number, double the other, cross out the evens, add what is left. It always works, and binary is the reason.

Name ____________________Date ____________

Tonight's idea

Grade 6 showed you this method. Halve the top number, dropping any half. Double the bottom number. Cross out columns where the top number is even. Add what is left on the bottom. Here is \(19 \times 12\).

halve199421
double12244896192

\(12 + 24 + 192 = 228\), which is \(19 \times 12\). Why is each step safe? Picture 19 rows of 12 dots.

Even number of rows. Cut the block in half and lay the halves side by side. Half as many rows, each twice as long, the same dots. Nothing to record, so cross it out.

Odd number of rows. Set one row aside first. It holds the bottom number of dots, so you keep that number.

Which columns are odd? Write 1 for odd and 0 for even, last column first: 10011. That is 19 in binary, the system that uses only 0 and 1 (Counting to 31 on one hand). The kept numbers are 12 times 1, 2 and 16, and \(1 + 2 + 16 = 19\).

Watch one: \(22 \times 15\)

halve2211521
double153060120240

Half of 11 is 5½, so write 5. Half of 5 is 2½, so write 2. The even numbers on top are 22 and 2, so those columns go. What is left: \(30 + 60 + 240 = 330\).

Check with binary. Last column first, odd and even give 10110, which is \(16 + 4 + 2 = 22\). The kept numbers are 15 times 2, 4 and 16.

See any number up to 255 in binary, one switch for each place: infinityclub.net/demos/binary.html.

Your turn

  1. Use the method to find \(14 \times 23\). Check it another way.
  2. Find \(37 \times 12\) with 37 as the number you halve. Then do it again halving the 12. Same answer? Which way is less work, and why?
  3. (a) Use your first table from exercise 2 to write 37 in binary. Check by adding place values. (b) 12 in binary is 1100. Without looking back, say which columns of your second table were kept.
  4. Look at the \(22 \times 15\) table. For each column, multiply the top number by the bottom number, then add every kept bottom number to its left. (For the column 5, 60 that is \(5 \times 60 + 30\).) What do you notice? Use the dots to explain it.

Stretch: thirds and triples

Invent the same kind of method with 3 in place of 2. Divide the top number by 3, dropping the remainder, and triple the bottom number. A remainder can now be 1 or 2. What should you do with a column in each case? Test your rule on \(14 \times 5\).

Answers

  1. Top: 14, 7, 3, 1. Bottom: 23, 46, 92, 184. Cross out the 14 column. \(46 + 92 + 184 = 322\). Check: \(14 \times 23 = 230 + 92 = 322\).
  2. Halving 37: top 37, 18, 9, 4, 2, 1; bottom 12, 24, 48, 96, 192, 384. Keep \(12 + 48 + 384 = 444\). Halving 12: top 12, 6, 3, 1; bottom 37, 74, 148, 296. Keep \(148 + 296 = 444\). The same. Halving the smaller number is less work: it reaches 1 in fewer steps, so there are fewer columns.
  3. (a) Odd, even, odd, even, even, odd. Last first: 100101, which is \(32 + 4 + 1 = 37\). (b) The 1s in 1100 are the 8 and the 4, so the last two columns were kept: \(4 \times 37 = 148\) and \(8 \times 37 = 296\).
  4. \(22 \times 15 = 330\). \(11 \times 30 = 330\). \(5 \times 60 + 30 = 330\). \(2 \times 120 + 30 + 60 = 330\). \(1 \times 240 + 30 + 60 = 330\). Always 330. The dots still in the block, plus the dots set aside so far, are all the dots you started with. No step loses any.

Stretch. A remainder of 1 means one row of dots set aside: add the bottom number once. A remainder of 2 means two rows: add it twice. A remainder of 0 means cross it out. For \(14 \times 5\): top 14, 4, 1; bottom 5, 15, 45; remainders 2, 1, 1. So \(2 \times 5 + 15 + 45 = 70\).
