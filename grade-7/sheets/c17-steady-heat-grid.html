How hot is the middle of the plate?

Heat a metal plate along one edge and keep the others cold. Once things settle, every spot is the average of the spots around it.

Name ____________________Date ____________

Tonight's idea

Hold one edge of a metal plate at 100 degrees and the other edges at 0. Heat flows from hot to cold until nothing changes. That settled pattern is a steady state.

In a steady state, a spot hotter than its surroundings would lose heat and cool. A colder spot would warm up. So every spot sits at the average of the spots around it. Now cut the plate into small square cells, with the border cells held fixed.

In the steady state, each inside cell equals the average of its four neighbours: up, down, left and right. Diagonal cells do not count.

The grid is a model of an even plate that loses no heat to the air. Smaller cells follow a real plate more closely. The height of a gently sloping soap film on a bent wire follows nearly the same rule.

One way to find the numbers is relaxation. Guess every inside cell. Then replace each one by the average of its neighbours, over and over. The numbers creep towards the steady state.

Watch one: one cell, then two

One inside cell has neighbours 0, 0, 100 and 100. Its steady temperature is their average, 50. Now take a row of two inside cells, \(a\) and \(b\). The left border is held at 240 and the rest at 0. The corners are left out, because no inside cell touches one along an edge.

The rule for each cell says \(a = (240 + 0 + 0 + b) \div 4\) and \(b = (a + 0 + 0 + 0) \div 4\). The second gives \(a = 4b\). The first gives \(4a = 240 + b\), so \(16b = 240 + b\), \(15b = 240\) and \(b = 16\). Then \(a = 64\). Check: \((240 + 16) \div 4 = 64\) and \(64 \div 4 = 16\).

Relaxation gets there gradually. Start with \(a = b = 0\). In each round, work out both new values from the old ones. Round 1 gives 60 and 0. Round 2 gives 60 and 15. Round 3 gives 63.75 and 15, creeping towards 64 and 16.

Your turn

  1. Use the left plate: top border 160, the rest 0. Start with \(a\), \(b\), \(c\) and \(d\) all 0. Do three rounds of relaxation, each time finding all four new values from the old ones. Write the values after each round.
  2. Now find the exact steady state of the same plate. (a) Flip the plate left to right and its border looks the same. What does that tell you about \(a\) and \(b\), and about \(c\) and \(d\)? (b) Write the rule for \(a\) and the rule for \(c\), then solve them. (c) How far short of the exact values was each cell after rounds 1, 2 and 3? What will the gap be after round 4? Will relaxation ever land exactly on the answer?
  3. Use the right plate: top border 100, the rest 0. Call the centre cell's steady value \(m\). (a) Give the plate a quarter turn, so the hot edge is on the right. What is the centre cell now? (b) Picture four copies, each with a different edge hot. Add them cell by cell. What is each border cell of the sum? (c) The sum still obeys the rule, and an all-100 border settles at 100 in every cell. Find \(m\).
  4. Same plate. (a) Predict which inside cell is hottest and which is coldest, and say why. (b) The top-left inside cell is about 42.86. Use the rule to find the top-middle one. (c) Why can no inside cell be hotter than 100? Hint: an average is never bigger than the biggest of its numbers.

Stretch: can two answers both be right?

Two friends fill in the same plate. Their borders match and both grids obey the rule. Subtract one grid from the other, cell by cell. (a) What is the border of the difference? (b) Why does the difference obey the rule? (c) Use question 4(c), and its mirror image for cold cells, to show it is 0 everywhere.

Answers

  1. Round 1: \(a = b = (160 + 0 + 0 + 0) \div 4 = 40\) and \(c = d = 0\). Round 2: \(a = b = (160 + 0 + 40 + 0) \div 4 = 50\) and \(c = d = (40 + 0 + 0 + 0) \div 4 = 10\). Round 3: \(a = b = (160 + 0 + 50 + 10) \div 4 = 55\) and \(c = d = (50 + 0 + 0 + 10) \div 4 = 15\). Each cell uses only up, down, left and right. For \(a\) those are the 160 above, the 0 on its left, \(b\) and \(c\).
  2. (a) The flipped plate has the same border, so it has the same steady state. (Only one pattern fits a given border. The stretch shows why.) So \(a = b\) and \(c = d\). (b) \(a = (160 + 0 + b + c) \div 4\). With \(b = a\) this is \(4a = 160 + a + c\), so \(3a = 160 + c\). And \(c = (a + 0 + 0 + d) \div 4\) with \(d = c\) gives \(4c = a + c\), so \(a = 3c\). Then \(9c = 160 + c\), so \(c = 20\) and \(a = 60\). The steady state is 60, 60 on top and 20, 20 below. Check: \((160 + 0 + 60 + 20) \div 4 = 60\) and \((60 + 0 + 0 + 20) \div 4 = 20\). (c) Every cell was 20 short after round 1, 10 short after round 2 and 5 short after round 3. The gap halves each round, so it is 2.5 after round 4. Here is why: if all four cells are short by \(g\), the new \(a\) is \((160 + (60 - g) + (20 - g)) \div 4 = 60 - g \div 2\), and the same happens to \(c\). Half of a number that is not zero is never zero, so relaxation never lands exactly. It gets as close as you like.
  3. (a) Still \(m\). The rule treats up, down, left and right alike, so the turned plate has the same pattern, turned. The centre cell stays in the centre. (b) Each border cell is 100 in exactly one copy and 0 in the other three, so in the sum it is \(100 + 0 + 0 + 0 = 100\). (c) The centre of the sum is \(m + m + m + m = 4m\). The sum has an all-100 border, so it is 100 in every cell. So \(4m = 100\) and \(m = 25\). The centre is exactly 25 degrees, a quarter of the way from cold to hot.
  4. (a) Hottest: the top-middle inside cell. It touches the hot edge and is as far as it can be from the cold sides. Coldest: the two bottom corner inside cells, at about 7.14. Each touches two cold border cells and is far from the hot edge. The bottom-middle cell is a little warmer, about 9.82. (b) Its neighbours are 100 above, about 42.86 on each side (the top-right cell matches the top-left by the flip in question 2) and \(m = 25\) below. So it is about \((100 + 42.86 + 42.86 + 25) \div 4 = 210.72 \div 4 = 52.68\). (c) Look at the hottest inside cell and suppose it were above 100. No neighbour is hotter than it, and it is their average, so all four neighbours must be exactly as hot as it is. Then they are inside cells too, because border cells are at most 100. Step from cell to cell towards an edge and you reach an inside cell above 100 that touches the border. That border cell would have to be above 100 as well, which it is not. In the same way, no inside cell is below 0.

Stretch. (a) The borders match, so every border cell of the difference is 0. (b) Take one inside cell. Each friend's value is the average of that friend's four neighbours. The difference of two averages is the average of the differences: \((p + q + r + s) \div 4 - (P + Q + R + S) \div 4 = ((p - P) + (q - Q) + (r - R) + (s - S)) \div 4\). (c) The difference obeys the rule and its border is all 0. By question 4(c) no inside cell is above the hottest border cell, which is 0. By the mirror argument none is below 0. So the difference is 0 in every cell, and the two friends have the same grid. Only one pattern fits a given border. Questions 2 and 3 leaned on that.
