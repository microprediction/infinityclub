Reverse and add

Take a number, reverse it, add. Do it again. Most numbers turn into a palindrome fast. One small number has never been seen to.

Name ____________________Date ____________

Tonight's idea

A palindrome reads the same forwards and backwards. The numbers 363 and 4884 are palindromes. So is the word "level".

Here is a way to make them. Take a number. Write it backwards. Add the two. If the answer is a palindrome, stop. If not, do the same again with the answer.

\(57 + 75 = 132\), which is not a palindrome. \(132 + 231 = 363\), which is. Two steps.

Most numbers get there quickly. Every number below 196 gets there in the end. None is slower than 89, which needs 24 steps.

Then comes 196. People have run it on computers for millions of steps, and no palindrome has ever appeared. Nobody has proved that one never will. It is an open question: easy to ask, and still without an answer.

Watch one: start at 87

\(87 + 78 = 165\)
\(165 + 561 = 726\)
\(726 + 627 = 1353\)
\(1353 + 3531 = 4884\)

Four steps. Check each answer by reading it backwards: 165 backwards is 561, so it is not a palindrome yet. 4884 backwards is 4884, so stop.

Another simple rule that nobody fully understands: infinityclub.net/demos/collatz.html.

Your turn

  1. Reverse and add until you reach a palindrome. Say how many steps each one took. (a) 23 (b) 48 (c) 152
  2. Start at 68 and go until you reach a palindrome. Then start at 59. What do you notice?
  3. (a) Do one step for 14, for 32 and for 45. (b) For each, add the two digits of the start. Where does that sum show up in the answer? (c) Why does a two-digit number finish in one step when its digits add to 9 or less?
  4. \(196 + 691 = 887\). Nobody has seen 196 reach a palindrome. Without any more adding, what does that tell you about 691? What about 887?

Stretch: the elevens

Do one step for any three two-digit numbers. Divide each answer by 11. Then explain why one step on a two-digit number always gives a number in the 11 times table.

Answers

  1. (a) \(23 + 32 = 55\): one step. (b) \(48 + 84 = 132\), \(132 + 231 = 363\): two steps. (c) \(152 + 251 = 403\), \(403 + 304 = 707\): two steps.
  2. \(68 + 86 = 154\), \(154 + 451 = 605\), \(605 + 506 = 1111\): three steps. \(59 + 95 = 154\) as well, so from there 59 follows exactly the same path. Different starts can join up.
  3. (a) \(14 + 41 = 55\), \(32 + 23 = 55\), \(45 + 54 = 99\). (b) The digit sums are 5, 5 and 9. Both digits of each answer are that sum. (c) The ones column adds the two digits. The tens column adds the same two digits. If the sum is 9 or less nothing is carried, so both columns show the same digit. That is a palindrome.
  4. 691 and 196 give the same sum, because adding works in either order. After one step they are on the same path, so 691 has never been seen to reach a palindrome either. Nor has 887: it is on that path too.

Stretch. For example \(57 + 75 = 132 = 11 \times 12\) and \(23 + 32 = 55 = 11 \times 5\). Why: each digit is used twice, once as tens and once as ones. So each digit is counted \(10 + 1 = 11\) times. For 57 that is \(11 \times 5 + 11 \times 7 = 11 \times 12\). The answer is always 11 times the sum of the digits.
